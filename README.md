# SiteRest — прототип сайта

Статический многостраничный прототип. Блок о конкретных участниках студии удалён.

## Запуск локально

Нужен Node.js. Установка зависимостей не требуется.

```sh
npm run build
npm run check
python3 -m http.server 4173 --directory dist
```

## GitHub Pages

Готовая папка `docs/` рассчитана на репозиторий `Kriskis777/siterest`. После загрузки файлов в GitHub в **Settings → Pages** выберите **Deploy from a branch**, ветку **main**, папку **/docs**, затем **Save**.

Ожидаемый адрес после успешного развёртывания: `https://Kriskis777.github.io/siterest/`. Само наличие этого адреса в README не означает, что сайт уже размещён.

Если имя репозитория другое, пересоберите с `GITHUB_REPOSITORY=Kriskis777/имя-репозитория npm run build`.

## Что внутри

- Пять основных страниц: главная, проекты, два обзора работ, ресторанная посадочная.
- Служебные страницы карты, данных прототипа, результата формы и ошибки 404.
- Навигация, фильтры проектов, ответы на вопросы и демонстрационная форма.
- `build.mjs`, `marketing.mjs` — структура и тексты.
- `dist/` — версия для корневого адреса.
- `docs/` — версия для GitHub Pages с путями внутри репозитория.

## Форма и материалы

Форма готовит черновик в браузере. Она не отправляет обращения в студию и не сохраняет поля на сервере. Используйте тестовые данные. Права и точный вклад по обзорам проектов остаются на проверке; измеренные результаты не заявляются.

В пакет не входят финансовая таблица, бизнес-документы, исследовательский PDF, ключи, настройки подключений и история приватного репозитория Sites.
